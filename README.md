# Doughminator - Bakery Management & Ordering System

A Java console application designed to manage bakery sales operations, customer membership profiles, live menu inventory, and sales reporting.

---

## Features

- **Menu & Inventory Management:** View, add, modify, and remove menu items with automatic stock quantity tracking.
- **Order Processing:** Place itemised customer orders with real-time stock validation and status tracking (`Pending`, `In Progress`, `Completed`).
- **Customer Membership:** Register customers, track unique membership IDs, and view past order histories.
- **Reporting & Analytics:** Generate real-time reports detailing items sold, live inventory counts, and total sales revenue.

---
